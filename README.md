# MVメーカー（ウェブ版）

テーマを書くだけで、Google の AI が歌詞・曲・キャラクター・映像を作り、歌詞の字幕付きのミュージックビデオに仕上げるウェブページです。

** 使ってみる：https://mvmaker-web.vercel.app **（API キーがなくても「お試しモード」で流れを体験できます）

- インストールは不要です。パソコンの Chrome・Edge・Safari で開いて使います。
- 最初に Google の API キー（Google の AI を使うための鍵）を貼り付けます。料金は、キーの持ち主の Google アカウントに Google から直接請求されます。
- 使う AI は次のとおりです。
  - 文章：Gemini 3.8 Flash
  - 曲：Lyria
  - 画像：Nano Banana
  - 映像：Gemini Omni Flash
- 曲・画像・映像の AI は、ページを開くたびに Google のモデル一覧を確かめて、自動で最新版を使います（2026-10-13 時点では Lyria 3.5、Nano Banana 2.1、Omni 1.1 Flash）。新しい版で Google に断られたときは、動作を確かめた版に自動で戻します。
- 料金のかからない「お試しモード」で、MV ができるまでの流れを最後まで体験できます。

## API キーの守り方

- このページには作者のサーバーがありません。キーはブラウザから Google にだけ直接送られます。
- ブラウザの安全機能（Content Security Policy、通信先と実行できるプログラムを制限する仕組み）で、Google 以外への通信と、外部のプログラムの読み込みを禁止しています。
- キーは画面・アドレス欄・エラーの表示には出しません。
- キーを覚えておく期間は、利用者が次の 2 つから選びます。
  - 「このタブを閉じるまで」（おすすめ）
  - 「このパソコンに暗号化して保存」
- 画面の「キーを外す」で、いつでも消せます。

**限界**：次の場合は、キーを守れません。

- 同じパソコンで、悪意のあるブラウザ拡張機能が動いている場合
- 利用者のパソコン自体が乗っ取られている場合
- このページを置いたサーバー（公開先）が改ざんされた場合。このときは、保存してあるキーが利用者の操作なしに送られるおそれがあります

どのウェブサイトでも同じです。「このパソコンに保存する」を選ぶと、そのパソコンでこのページを開いた人は誰でもそのキーを使えます。暗号化は、パソコンのファイルを直接のぞかれたときの備えです。

**料金の自動停止**：料金の自動停止は、このページの見積もりで判断します。料金表にない新しい版の AI が出た場合は、基準の版の 3 倍で見積もり、画面に注意を出します。画面の「API キーの安全について」で、専用キーを作る、API の制限と予算のアラートを設定する、といった対策を案内しています。

## 自分のパソコンで動かす方法

1. このリポジトリのフォルダで、ターミナルから次のコマンドを実行します（Python 3 が必要です）。

```bash
python3 -m http.server 8765 --bind 127.0.0.1
```

2. Chrome で http://localhost:8765 を開きます。
3. 「お試しモードで始める」を押すと、料金なしで全部の工程を試せます。本物の MV を作るときは、API キーを貼り付けます。
4. 終わるときは、ターミナルで `control` キーを押しながら `C` を押します。

## 使い方の流れ

1. API キーを貼り付けて「キーを確認して始める」を押します。料金のかからない問い合わせでキーを確認します。
2. 「新しい MV を作る」で、テーマ・雰囲気・声・長さ（30〜90 秒）・画面の向き・上限額を決めます。
3. ステップ 1（歌詞）：AI が歌詞と絵コンテを作ります。歌詞は自由に書き換えられます。
4. ステップ 2（曲）：曲を聴いて決めます。気に入らなければ作り直せます。
5. ステップ 3（キャラクター）：見本の絵を 2 枚見て決めます。
6. ステップ 4（映像）：場面ごとに動画を作ります。1 本に数分かかります。
7. ステップ 5（完成）：書き出して「ダウンロードして保存」を押します。書き出しは MV と同じくらいの時間がかかり、そのあいだは画面を表示したままにします。

作った MV は、そのブラウザの中に保存されます。ほかのパソコンやブラウザからは見えません。

## 指示して直す

歌詞・曲・絵・場面の動画は、どれも「どう直したいか」を書いて作り直せます。
- 歌詞：「サビに叫ぶ言葉を入れて」など。いまの歌詞をもとに、指示したところだけを直します。
- 曲：「もっと速く激しく」など。歌詞はそのままで、曲を作り直します。
- 絵：「左の黒い四角を消して」「髪を青に」など。いまの絵をもとに直します。直した内容は、このあと作る場面の動画にも反映されます。
- 場面：各場面の「指示して作り直す」から指示します。

日本語の指示は、AI に渡す前に英語に訳します。そのための料金が、1 回につき 1 円未満かかります。

## 費用の目安

60 秒の MV 1 本で、作り直しなしなら約 7 ドル、作り直しを含めて 10 ドル前後です。大部分は動画の料金で、1 秒あたり約 0.10 ドルです。MV ごとに上限額を決められ、上限に届きそうになると自動で止まります。

## 料金の表示

- 料金は、Google の公式料金ページから読み取って表示します。公開後は、Vercel 上の仕組みが 1 日に 1 回ページを読み直します。手元で確認するときは、保存してある読み取り結果を使います。
- 料金表にまだ載っていない新しい版の AI は、料金が基準の版の 3 倍かかると仮定して金額を計算します。画面にもその旨を表示します。料金表に載ると、自動で正しい金額に切り替わります。
